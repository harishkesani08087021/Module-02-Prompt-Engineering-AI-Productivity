# Module 02 – Prompt Engineering & AI Productivity

**Internship module:** Day 6 – Day 10  
**Level:** Beginner

## Objectives
1. Practice zero-shot and few-shot prompting, roles, context, instructions, and constraints.
2. Create structured JSON outputs and prompts for summarization, classification, and generation.
3. Apply AI-assisted coding/debugging and evaluate prompts using reusable templates and testing reports.
4. Build an AI Productivity Toolkit for summarization, email, resume, coding, and research assistance.

## Repository contents
- `Module_02_Prompt_Engineering_AI_Productivity.ipynb` – Google Colab/Jupyter practical notebook.
- `README.md` – Project overview and usage instructions.

## Run in Google Colab
1. Download the `.ipynb` notebook from this repository.
2. Open https://colab.research.google.com/
3. Choose **File → Upload notebook** and select the notebook.
4. Run cells from top to bottom.
5. Complete the activities and fill in the prompt evaluation observations.
6. Save a copy to Google Drive and share it with Viewer access if required by your internship portal.

## Topics covered
- Zero-shot and few-shot prompting
- Role, context, instruction, and constraints
- JSON and structured outputs
- Summarization, classification, and generation
- AI-assisted coding and debugging
- Prompt evaluation and testing reports
- Reusable AI productivity workflows

## Requirements
- Google account for Colab
- Python 3
- Internet connection to access Colab and an AI assistant

No API key is required for the core exercises. The notebook uses prompt templates that can be tested in an AI assistant of your choice.

## Responsible use
Do not enter passwords, private data, or confidential information into AI tools. Verify facts, test generated code, and review outputs for errors and bias before using them.
